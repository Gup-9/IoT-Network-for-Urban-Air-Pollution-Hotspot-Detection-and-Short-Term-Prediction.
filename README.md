# -IoT-Network-for-Urban-Air-Pollution-Hotspot-Detection-and-Short-Term-Prediction.
An affordable distributed IoT network that detects, maps, and predicts urban air pollution hotspots using real-time sensor data, LoRa communication, and machine learning.
# -Project Overview
Urban air pollution can vary significantly from one location to another due to traffic, industrial activity, weather conditions, and other factors. Conventional monitoring stations are expensive and therefore limited in number.
