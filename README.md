# IoT-Network-for-Urban-Air-Pollution-Hotspot-Detection-and-Short-Term-Prediction.
An affordable distributed IoT network that detects, maps, and predicts urban air pollution hotspots using real-time sensor data, LoRa communication, and machine learning.
# -Project Overview
Urban air pollution can vary significantly from one location to another due to traffic, industrial activity, weather conditions, and other factors. Conventional monitoring stations are expensive and therefore limited in number.\
\
This project aims to develop a low-cost distributed air-quality monitoring network that can:\
1.Monitor PM2.5 and PM10 levels at multiple locations\
2.Collect temperature, humidity, and gas-related air-quality data\
3.Determine the geographical location of measurements\
4.Transmit sensor data over long distances using LoRa\
5.Create a real-time pollution hotspot map\
6.Analyze historical pollution patterns\
7.Predict potential pollution hotspots using machine learning\
